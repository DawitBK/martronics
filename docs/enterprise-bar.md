# Enterprise bar: Martronics scorecard

**DONE** means there is code and a test (the evidence column says where), **PARTIAL** means part
of it exists, **TODO** means it does not exist yet. The status is deliberately honest.

Status as of 2026-10-17 (API slices: identity, catalog, cart, orders, payments).

| #   | Requirement                                              | Status  | Evidence / what is missing                                                                                                                                                                                                                                                                                                               |

An admin cannot change their own role. Fine-grained permissions are TODO.                                                                                           |
| 2   | Append-only audit trail, written in the same transaction | DONE    | `audit_log` with a trigger that rejects UPDATE/DELETE/TRUNCATE (`drizzle/0001_*.sql`); rows for every catalog, user, order and payment change; tests in `identity.int.test.ts` and `orders.int.test.ts`.                                                                                                                                 |
